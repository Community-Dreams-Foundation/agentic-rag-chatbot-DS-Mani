# Agentic RAG Chatbot Demo Document

## Chunking
This demo describes a retrieval-augmented generation (RAG) pipeline with section-aware
chunking. Documents are split into sections using headings, then each section is
chunked into roughly 800-character pieces with about 100 characters of overlap. Each
chunk stores a source filename, a section title, and a chunk_id for citations.

## Retrieval
Retrieval uses a hybrid scoring strategy. BM25 provides lexical relevance based on
query terms, and semantic similarity comes from embeddings. The two signals are
combined into a hybrid score, then reranked to prioritize chunks with stronger
query-term alignment.

## Citations
Citations include the source file, a locator (page/section/chunk), and a short
snippet from the chunk to show where the answer came from.
